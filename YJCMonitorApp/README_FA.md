# YJC Monitor - نسخه موبایل (Kivy)

این پوشه نسخه‌ی موبایل (اندروید) پروژه‌ی YJC Monitor است که با فریم‌ورک
Kivy نوشته شده و برای تبدیل به APK آماده است.

## ساختار پروژه

```
YJCMonitorApp/
├── main.py              اپ Kivy (رابط کاربری: صفحه اصلی + تنظیمات)
├── engine.py             موتور پایش RSS که در پس‌زمینه (Thread) اجرا می‌شود
├── yjcsettings.py        ذخیره/خواندن تنظیمات (feeds، بازه زمانی، توکن بله)
├── core/                 همان منطق نسخه دسکتاپ (parser, monitor, formatter, database, notifier)
├── buildozer.spec        تنظیمات ساخت APK
└── .github/workflows/    ساخت خودکار APK با GitHub Actions
```

## چه چیزی تغییر کرده نسبت به نسخه دسکتاپ؟

- به‌جای `config.py` ثابت، همه‌چیز (فیدهای فعال، بازه بررسی، توکن ربات بله،
  chat_id) از صفحه‌ی «تنظیمات» در خود اپ قابل تغییر است و در
  `settings.json` داخل حافظه‌ی اختصاصی اپ ذخیره می‌شود.
- کپی‌کردن در Clipboard (`pyperclip`) حذف شده — همان‌طور که قبلاً در نسخه
  دسکتاپ هم غیرفعالش کردیم؛ روی موبایل اصلاً معنا نداشت.
- به‌جای `time.sleep` یک‌جا، از یک حلقه‌ی قابل‌قطع استفاده شده تا با زدن
  دکمه‌ی «توقف» بلافاصله متوقف شود.
- هنگام ارسال موفق هر خبر، یک اعلان (notification) اندرویدی هم نمایش داده
  می‌شود (با کتابخانه‌ی `plyer`).
- ماژول `core/ai.py` (خلاصه‌سازی با هوش مصنوعی) در این نسخه منتقل نشده،
  چون در نسخه دسکتاپ هم اصلاً در مسیر اصلی برنامه استفاده نمی‌شد. اگر
  لازمش داشتید بگویید تا اضافه‌اش کنم.

## ⚠️ محدودیت مهم: اجرا در پس‌زمینه

این نسخه، پایش RSS را در یک Thread داخل خودِ اپ اجرا می‌کند. یعنی:

- تا وقتی اپ باز است (حتی اگر صفحه خاموش باشد یا اپ در پس‌زمینه‌ی نزدیک
  باشد) کار می‌کند.
- ولی اندروید معمولاً پس از چند دقیقه بی‌فعالیتِ اپ (بسته به برند گوشی —
  به‌خصوص شیائومی/هواوی که مدیریت باتری سخت‌گیرانه دارند)، اپ را از
  حافظه خارج می‌کند و پایش متوقف می‌شود.
- برای اجرای واقعی و پایدار ۲۴ ساعته حتی وقتی اپ کاملاً بسته است، باید
  یک **Foreground Service** جداگانه (با اعلان دائمی) به پروژه اضافه شود.
  این یک قدم توسعه‌ی جداست؛ اگر لازمش داشتید بگویید تا در یک نسخه‌ی
  بعدی اضافه‌اش کنم.

راه‌حل ساده برای الان: در تنظیمات گوشی، بهینه‌سازی باتری را برای این اپ
غیرفعال کنید (Battery optimization → Don't optimize) تا شانس ماندن اپ در
حافظه بیشتر شود.

## تست روی کامپیوتر (قبل از ساخت APK)

```bash
pip install kivy requests feedparser beautifulsoup4 plyer
python main.py
```

با این کار همان اپ روی دسکتاپ در یک پنجره اجرا می‌شود و می‌توانید قبل از
build گرفتن، تنظیمات و شروع/توقف را امتحان کنید.

## ساخت APK

### روش ۱: GitHub Actions (پیشنهادی، بدون نیاز به لینوکس شخصی)

1. این پوشه را در یک ریپازیتوری گیت‌هاب (خصوصی یا عمومی) push کنید.
2. به تب **Actions** پروژه در گیت‌هاب بروید؛ workflow با نام
   **Build APK** به‌صورت خودکار روی هر push اجرا می‌شود
   (یا از دکمه‌ی **Run workflow** به‌صورت دستی اجرایش کنید).
3. بعد از پایان اجرا (حدود ۱۵ تا ۳۰ دقیقه، به‌خصوص بار اول)، در پایین
   صفحه‌ی همان اجرا (run) بخش **Artifacts** را باز کنید و فایل
   `yjcmonitor-debug-apk` را دانلود کنید. داخلش فایل `.apk` است.

### روش ۲: ساخت محلی روی لینوکس (یا WSL در ویندوز)

```bash
sudo apt update
sudo apt install -y git zip unzip openjdk-17-jdk python3-pip \
    autoconf libtool pkg-config zlib1g-dev libncurses5-dev \
    libncursesw5-dev cmake libffi-dev libssl-dev

pip install --user buildozer cython

cd YJCMonitorApp
buildozer -v android debug
```

فایل خروجی در `bin/yjcmonitor-1.0-arm64-v8a_armeabi-v7a-debug.apk` (یا
مشابه) ساخته می‌شود. بار اول ممکن است طولانی باشد چون Buildozer باید
Android SDK/NDK را دانلود کند.

## نصب روی گوشی

1. فایل `.apk` را به گوشی منتقل کنید (کابل، تلگرام به خودتان، گوگل درایو و...).
2. روی فایل بزنید؛ اگر پیام «نصب از منابع ناشناس مجاز نیست» آمد، در
   تنظیمات گوشی (Settings → Apps → Special access → Install unknown apps)
   برای همان اپ (مثلاً فایل منیجر یا مرورگر) اجازه بدهید.
3. نصب را تایید کنید.
4. بعد از باز کردن اپ، اول به تنظیمات بروید و توکن ربات بله و chat_id را
   وارد کنید، فیدهای موردنظر را فعال کنید، بازه بررسی را تنظیم کنید و
   ذخیره بزنید. بعد به صفحه اصلی برگردید و «شروع پایش» را بزنید.

## نکته درباره‌ی نسخه‌ی release (برای انتشار در بازار اپ)

خروجی `buildozer android debug` یک APK امضا‌شده با کلید تست است و فقط
برای نصب مستقیم روی گوشی مناسب است. اگر بخواهید در بازارهایی مثل کافه‌بازار
یا مایکت منتشرش کنید، باید با `buildozer android release` و یک کلید
امضای واقعی (keystore) بسازیدش — که آموزشش را هم در صورت نیاز می‌دهم.
